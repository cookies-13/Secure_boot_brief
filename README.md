# Краткий обзор безопасной загрузки 
Эта статья - первый шаг в теме безопасной загрузки. Материал ориентирован на студентов профильных направлений и IT-специалистов, приступающих к изучению принципов доверенной загрузки.

Теоретическая часть, а именно определения, алогритмы, логика проверки и цепочка доверия описаны независимо от аппаратной платформы и применимы к широкому спектру устройств, использующих современные аппаратные и программные решения. Однако практическая реализация этапов загрузки и конфигурационые файлы специфичны для проприетарного загузчика, который применяется только на архитектуре Broadcom (в случае Raspberry PI 4B это BCM2711).

> В образовательных целях и для снижения порога входа в теоретической части использованы некоторые собенности и абстракции и упрощения. Однако, никто не хочет учиться неправильно, так что при обнаружении неточностей - создайте issue или предложите pull request)
